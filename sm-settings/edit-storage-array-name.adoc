= 在 SANtricity System Manager 中编辑存储阵列名称
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改SANtricity 系统管理器标题栏中显示的存储阵列名称。

.步骤
. 从左侧面板中，选择 *System*。
. 在*常规*下，单击*编辑存储阵列名称*。
+
此时将显示编辑存储阵列名称对话框。

. 在*名称*字段中输入新名称。
+
名称可以包含字母、数字以及特殊字符下划线(_)、短划线(-)和哈希符号(#)。名称不能包含空格。一个名称的最大长度可以为30个字符。此名称必须是唯一的。

. 单击 * 保存 * 。


.结果
新名称将显示在SANtricity 系统管理器的标题栏中。
