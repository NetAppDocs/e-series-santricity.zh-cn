= 在 SANtricity System Manager 中充当客户端时为控制器导入证书
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果控制器由于无法验证网络服务器的信任链而拒绝某个连接，则可以从"受信任的证书"页面导入一个允许控制器（作为客户端）接受来自该服务器的通信的证书。

.开始之前
* 您必须使用包含安全管理员权限的用户配置文件登录。否则、不会显示证书功能。
* 证书文件安装在本地系统上。


.关于此任务
如果要允许其他服务器联系控制器（例如，LDAP 服务器或使用 TLS 的 syslog 服务器），则可能需要从"受信任的证书"页面导入证书。

.步骤
. 从左侧面板中，选择菜单：Certificates[Trusted certificates]，然后选择 *Import*。
+
此时将打开一个对话框、用于导入可信证书文件。

. 单击*浏览*以选择控制器的证书文件。
+
文件名显示在对话框中。

. 单击 * 导入 * 。


.结果
这些文件将上传并进行验证。
