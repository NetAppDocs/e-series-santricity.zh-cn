= 在 SANtricity System Manager 中编辑警报的电子邮件地址
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改接收电子邮件警报的收件人的电子邮件地址。

.开始之前
您要编辑的电子邮件地址必须在"电子邮件警报"页面上定义。

.步骤
. 从左侧面板中，选择菜单：警报[Email alerts]。
. 从*电子邮件地址*表中、选择要更改的地址、然后单击最右侧的*编辑*(铅笔)图标。
+
该行将变为可编辑字段。

. 输入新地址、然后单击*保存*(复选标记)图标。
+
[NOTE]
====
如果要取消更改、请选择*取消*(X)图标。

====


.结果
电子邮件警报页面显示更新后的电子邮件地址。
