= 在 SANtricity System Manager 中查看 NVMe over Fabrics 统计信息
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看有关通过网络结构连接到存储阵列的NVMe的数据。

.关于此任务
System Manager会显示这些类型的基于网络结构的NVMe统计信息。所有统计信息均为只读、无法设置。

* *NVMe 子系统* -- 显示 NVMe 控制器及其队列的统计信息。NVMe 控制器提供主机与存储阵列中的命名空间之间的访问路径。您可以查看连接失败、重置和关闭等项目的 NVMe 子系统统计信息。
* *RDMA statistics* -- 提供 RDMA 接口上所有 NVMe over Fabrics 端口的统计数据，其中包括与每个交换机端口关联的性能统计数据和链路错误信息。此选项卡仅在 NVMe over Fabrics 端口可用时显示。


您可以将其中每个统计信息作为原始统计信息或基线统计信息进行查看。原始统计信息是自控制器启动以来收集的所有统计信息。基线统计信息是自设置基线时间以来收集的时间点统计信息。

.步骤
. 从左侧面板中，选择 *System*。
. 选择 *View NVMe over Fabrics statistics*。
. *可选：*要设置基线、请单击*设置新基线*。
+
设置基线将为统计信息的收集设置一个新的起点。所有NVMe统计信息都使用相同的基线。
