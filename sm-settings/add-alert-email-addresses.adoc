= 在 SANtricity System Manager 中添加警报的电子邮件地址
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您最多可以为电子邮件警报添加20个收件人。

.步骤
. 从左侧面板中，选择菜单：警报[Email alerts]。
. 选择*添加电子邮件*。
+
此时将打开添加电子邮件对话框。

. 在空字段中、输入新的电子邮件地址。如果要添加多个地址、请选择*添加其他电子邮件*以打开另一个字段。
. 单击 * 添加 * 。


.结果
电子邮件警报页面将显示新电子邮件地址。
