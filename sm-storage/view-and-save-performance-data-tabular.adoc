= 在 SANtricity System Manager 中查看和保存表格性能数据
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以以表格形式查看和保存性能图形数据。这样、您可以筛选要显示的数据。

.步骤
. 在 Performance 页面中，单击 *Go to table view*。
+
此时将显示一个表、其中列出了选定对象的所有性能数据。

. 使用*对象类型*和*时间范围*选择要显示的数据，然后单击*刷新*。
. 单击*显示/隐藏列*按钮以选择要包含在表中的列。
+
您可以单击每个复选框以选择或取消选择某个项目。

. 从表格菜单中选择 *Export to CSV*，将表格视图保存为逗号分隔值 (CSV) 文件。
+
根据您的浏览器设置、文件将被保存、或者系统会提示您选择文件的名称和位置。

+
默认文件名格式为 `performanceStatistics-<storage array name>-yyyy-mm-dd_hh-mm-ss.csv`，其中包括存储阵列名称以及导出文件的日期和时间。
