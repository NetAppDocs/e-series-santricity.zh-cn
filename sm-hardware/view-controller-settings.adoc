= 在 SANtricity System Manager 中查看控制器设置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看有关控制器的信息、例如主机接口、驱动器接口和管理端口的状态。

.步骤
. 从左侧面板中，选择菜单：Hardware[Controllers and components]。
. 执行以下操作之一以显示控制器设置：
+
** 单击控制器以显示上下文菜单、然后选择*查看设置*。
** 选择控制器图标(在*磁盘架*下拉列表旁边)。对于双工配置、从对话框中选择*控制器A*或*控制器B*、然后单击*下一步*。
+
控制器设置滑动菜单打开。



. 请查看各部分以在控制器属性设置之间移动。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 部分 | Description 


 a| 
详细信息
 a| 
显示控制器状态、日期/时间、型号名称和更换零件号。



 a| 
当前配置
 a| 
显示当前固件版本和 NVRAM 版本。



 a| 
数据缓存
 a| 
显示数据缓存总计。



 a| 
数据缓存模块
 a| 
显示缓存模块位置、状态和容量。



 a| 
处理器缓存
 a| 
显示处理器缓存总计。



 a| 
缓存备份设备
 a| 
显示缓存备份设备位置、状态和容量。



 a| 
主机接口
 a| 
显示每个端口的主机接口信息和链路状态。



 a| 
驱动器接口
 a| 
显示每个端口的驱动器接口信息和链路状态。



 a| 
管理端口设置
 a| 
显示管理端口详细信息，包括控制器主机名、远程登录和 IP 网络设置。



 a| 
域名系统 (DNS) 服务器设置
 a| 
显示 DNS 配置、主 DNS 服务器和备份 DNS 服务器。



 a| 
网络时间协议 (NTP) 服务器设置
 a| 
显示 NTP 服务和 NTP 服务器配置详细信息。

|===
