= 更改 SANtricity System Manager 中架子的视图顺序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改硬件页面上显示的磁盘架顺序、以匹配机柜中磁盘架的物理顺序。

.步骤
. 从左侧面板中，选择菜单：Hardware[Controllers and components]。
. 选择货架的下拉列表，然后选择*Change order*以重新排列"硬件"页面上显示的货架顺序。
