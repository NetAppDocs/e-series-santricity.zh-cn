= 在 SANtricity System Manager 中打开驱动器定位器指示灯
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在硬件页面中、您可以打开定位器指示灯以查找驱动器在存储阵列中的物理位置。

.关于此任务
您可以找到硬件页面上显示的单个或多个驱动器。

.步骤
. 从左侧面板中，选择菜单：Hardware[Drives]。
. 要查找一个或多个驱动器、请执行以下操作之一：
+
** *单个驱动器* -- 从货架图形中，找到要在阵列中实际定位的驱动器。单击驱动器以显示其上下文菜单，然后选择 *打开定位灯*。
+
驱动器的定位灯亮起。找到驱动器后、返回对话框并选择*关闭*。

** *多个驱动器* -- 在筛选器字段中，选择物理驱动器类型和逻辑驱动器类型。符合条件的驱动器数量显示在该字段的最右侧。接下来，单击*打开定位灯*。物理定位驱动器后，返回对话框并选择*关闭*。
